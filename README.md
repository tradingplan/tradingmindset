# Trading Mindset & Discipline Companion 🛡️

Aplicativo mobile desenvolvido em **React Native + Expo SDK 57** para blindagem mental, controle de ansiedade/FOMO e disciplina operacional para traders.

## 🚀 Como Rodar Localmente

```bash
# 1. Instalar dependências
npm install --legacy-peer-deps

# 2. Iniciar o servidor Metro
npm start -c
```

Abra o aplicativo **Expo Go** no celular e leia o QR Code gerado no terminal.
