# Trading Mindset & Discipline Companion 🛡️

Aplicativo mobile e web desenvolvido em **React Native + Expo SDK 57 + TypeScript** para blindagem mental, controle de ansiedade/FOMO, disciplina operacional e auditoria comportamental para traders de alta performance.

---

## ⚡ Principais Módulos & Recursos

* **📋 Protocolo Operacional:** Checklists estruturados de Pré-Market, Sniper Entry Check e Pós-Market com cálculo diário de Score de Disciplina.
* **🔮 Tarot Trader:** 22 cartas de arquétipos comportamentais para diagnóstico precoce de viés cognitivo (Revenge Trading, FOMO, Overtrading, Hesitação), cálculo de carga psicológica (`psych_load`) e histórico de 90 dias.
* **🎧 Audioteca de Alta Performance:** Catálogo com +20 faixas narradas, frequências binaurais geradas em tempo real (Alfa 10Hz, Teta 6Hz), auto-hipnose e suporte completo a download offline.
* **🚨 S.O.S Anti-Tilt:** Intervenção imediata com respiração guiada 4-7-8 e timer de resfriamento obrigatório pós-loss.
* **🔔 Sistema de Alarmes:** Notificações locais para rotinas de pregão e alertas duplos inteligentes de notícias macroeconômicas (Payroll, CPI, FOMC, Copom).
* **🛡️ Camada de Acesso & Proteção (Opção A):** Arquitetura Freemium com 3 faixas gratuitas de degustação, plano **Trader PRO** integrado a checkout externo (Hotmart/Kiwify) e privilégios totais de **Superadmin** com sincronização em nuvem via Supabase.

## 🚀 Como Rodar Localmente

```bash
# 1. Instalar dependências
npm install --legacy-peer-deps

# 2. Iniciar o servidor Metro (Mobile)
npm start -c

# 3. Iniciar a versão Web
npm run web

# 4. Executar os testes automatizados do Tarot Trader
npm run test:tarot
```

Abra o aplicativo **Expo Go** no celular e leia o QR Code gerado no terminal, ou acerte a tecla `a` para rodar no Emulador Android.
